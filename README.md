# Пилот Бори на доске «Калуга»

Боря читает два учебных чата и выбранные рабочие карточки «Продлений» и «Покупок и решений» Калуги. Менеджер начинает запрос в чате нужной карточки с «Боря», «@Боря» или «/Боря». Несколько обращений в разных карточках можно оставить подряд. Ответ на каждое появится в том же чате. Старые обращения «Помощник», `/bot` и «Нужен собственник» тоже поддерживаются.

Боря предлагает формулировку и следующий шаг для менеджера. При согласованной дате контакта он советует сохранить дату и канал. Если раньше появился конкретный вариант, который решает вопрос клиента, Боря может предложить одно короткое сообщение. При отсутствии ответа менеджер ждёт согласованного дня. При неопределённом «потом» Боря помогает выяснить причину и согласовать дату, канал и цель. Просьба прекратить контакты завершает обсуждение. Цены, скидки, рассрочки, акции и нестандартные условия передаются собственнику. Ответ в чате не называет и не обещает условия. Боря не пишет клиентам и не редактирует карточки или дедлайны. Менеджер формирует ссылку на оплату вручную. Администратор занимается записью на урок.

Чтобы выпустить ключ от имени Бори, вручную запустите `register-borya-key.ps1` из уже открытого PowerShell. Скрипт запрашивает пароль YouGile без отображения, отправляет его только в официальный API YouGile по HTTPS и проверяет владельца выпущенного ключа. Ключ хранится в зашифрованном виде в локальном профиле Windows вне OneDrive. Пароль в файл не записывается.

Локальный запуск через `start-local.ps1` открывает фоновый процесс без окна. Пока компьютер включён и есть сеть, он каждые 20 секунд начинает проверку учебных карточек и очередной группы рабочих задач. Полный проход по рабочим карточкам занимает около минуты или дольше при замедлении API. Личные и групповые беседы не проверяются. В локальный статус пишутся время проверки и счётчики, без текстов сообщений. После перезагрузки фоновый процесс нужно запустить заново.

Для запуска в Yandex Cloud Functions используется приватная функция с обработчиком `index.handler` и Python 3.12. В функции укажите `YOUGILE_TOKEN` через Lockbox и `YOUGILE_BOT_USER_ID` отдельного аккаунта «Боря». До чтения чатов код сверяет владельца ключа и требует, чтобы у него не было административных прав. Запускайте функцию таймером раз в минуту с одним одновременным обработчиком. Каждый вызов проверяет учебные карточки и очередную группу рабочих. При 13 карточках полный проход занимает до четырёх минут в штатном режиме. После проверки облачного запуска остановите локальный процесс, чтобы обе копии не отвечали одновременно. Для локального теста передайте функции `run` ключ и ID отдельного аккаунта. Секреты в этот каталог не записываются.

Для уведомлений настройте `TELEGRAM_BOT_TOKEN` через Lockbox и укажите `OWNER_CHAT_ID` подтверждённого личного чата собственника. Если задан `OWNER_TASK_URL`, сообщение содержит кнопку с переходом в тестовую задачу. В Telegram передаётся только общий запрос на решение. Ответы в YouGile и уведомления имеют отдельные отметки обработки. Это позволяет повторить оповещение после сбоя без повторного ответа в YouGile.

Учебные ответы подготовлены правилами для возражений по цене, сроку и согласованию скидки. Пилот работает по двум указанным карточкам и не обращается к реальным сделкам AlfaCRM.
